## 第二部分　小位宽 RSA（`src/crypto/rsa.java`）

### 6. 固定参数与约定（`rsa.java`）

| 项目 | 说明 |
|---|---|
| RSA 类型 | 教科书 RSA，无填充；支持 64 / 128 / 256 位 |
| 随机性 | 全部来自显式传入的 `java.util.Random`，**固定种子即可复现** |
| 明文范围 | 单块明文必须满足 `0 ≤ m < n`，越界即抛异常 |
| 字符串编码 | UTF-8 分块，每块 `floor((b−1)/8) − 1` 字节（`b` = n 的位宽） |
| 块内哨兵 | 每块前置 1 字节 `0x01`，用于保留前导 0 并作完整性校验 |
| 公开指数 | 优先 65537，若 `gcd(e, φ(n)) ≠ 1` 依次退化为 3 / 5 / 17 / 257 / 奇数搜索 |

各密钥的每块明文容量：64 位 → 6 字节；128 位 → 14 字节；256 位 → 30 字节。

复现方式：

```bash
javac --release 17 -encoding UTF-8 -d out src/crypto/bigint_ops.java src/crypto/rsa.java
java -Dfile.encoding=UTF-8 -cp out crypto.rsa
```

### 11. 交叉验证记录（第二条路径）

`rsa.java` 主实现**不使用** `BigInteger.modPow` / `gcd` / `isProbablePrime`（这三个方法只允许出现在交叉验证脚本中）。
以下由 **Python 3.13 内置 `pow(m, e, n)`** 独立复算，与 Java 主实现输出逐位一致：

```text
p*q == n                       : True
e*d mod phi == 1               : True
m= 2  c=4208667619380246267    pass=True  roundtrip=True
m=42  c=10689628196788140947   pass=True  roundtrip=True
m= 0  c=0                      pass=True  roundtrip=True
m= 1  c=1                      pass=True  roundtrip=True
"在线书店" 密文块  : ['0x1a10fff7f7b353c3', '0x7921df78bf1b99e0']  一致: True
"A" 密文块         : 0x7d2164a820b5ef21                          一致: True
```

第一部分第 3、4 节（3233 密钥、字节级）的同类核对：

```text
"你好" 逐字节加密 : [293, 2044, 1379, 1544, 2414, 2044]          一致: True
"你好" 解密密文   : 还原为 "你好"                                 一致: True
"A"*100 加密      : 65^17 mod 3233 = 2790                        一致: True
```

> 说明：Java 侧的「标准库交叉验证」脚本 `src/crypto/verify_with_stdlib.*` 由组内负责交叉验证的成员单独提交，
> 计划用 `java.math.BigInteger.modPow` 复算同一组密钥与明文；在本表成文时该脚本尚未入库，
> 因此本节先给出 **Python 3.13 内置 `pow`** 的独立复算结果作为第二条路径的证据。

### 12. 安全边界实测（支撑"小位宽不能用于生产"）

| 实验 | 输入 | 实测结果 | 结论 |
| :--- | :--- | :--- | :--- |
| Pollard ρ 分解 | K1 的 n = 11387562574731347071 | 71.88 ms 内分解出因子 2878846133 | 64 位模数可被离线瞬间攻破 |
| 确定性 | 同一 m 连续两次加密 | 密文完全相同 | 无填充 ⇒ 无随机性，可字典攻击 |
| 乘法同态 | E(m1)·E(m2) mod n | `== E(m1·m2 mod n)` | 攻击者可无密钥操纵明文 |

### 13. 结论

- RSA 加解密**结果可复现**：固定种子 → 固定密钥 → 固定密文，重复运行一致。
- **数学正确**：与教科书公开向量、Python 内置 `pow` 双重核对一致。
- **边界覆盖**：0、1、n−1、n、负数、空串、超长输入、非法输入、密文篡改均有明确预期行为。
