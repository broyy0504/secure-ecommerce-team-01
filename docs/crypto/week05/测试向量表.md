#### 1.6 Miller-Rabin —— 素数判为真

| 输入                                                     | 期望     |
|:------------------------------------------------------ |:------ |
| `2`、`3`、`5`、`7`、`13`                                   | `True` |
| `7919`、`104729`                                        | `True` |
| `2147483647`（2³¹−1）                                    | `True` |
| `2305843009213693951`（2⁶¹−1）                           | `True` |
| `170141183460469231731687303715884105727`（2¹²⁷−1，梅森素数） | `True` |

> 当 `n < 3317044064679887385961981`（约 3.317×10²⁴）时使用确定性见证集，结论确定；更大时退化为概率判定（误判率 ≤ 4⁻ᵏ）。

#### 1.7 Miller-Rabin —— 合数与伪素数必须判为假

| 输入                                              | 期望      |
|:----------------------------------------------- |:------- |
| `0`、`1`、`4`、`9`、`15`、`21`、`25`、`100`            | `False` |
| `341`、`2047`（费马伪素数）                             | `False` |
| `561`、`1105`、`1729`（卡迈克尔数）                      | `False` |
| `1000000007 × 1000000009 = 1000000016000000063` | `False` |

> 只用费马小定理会被 341 / 2047 / 561 / 1105 / 1729 骗过，Miller-Rabin 不会。

#### 1.8 随机素数生成 `random_prime` —— 固定种子可复现

| 随机源                | 位长  | 期望素数                   |
|:------------------ | ---:|:---------------------- |
| `JavaRandom(42)`   | 32  | `4153081357`           |
| `JavaRandom(2026)` | 64  | `15914823978284633399` |

校验：同一 `JavaRandom(42)` 连续生成两次结果相同；32 位值确为素数且位长为 32；64 位值确为素数且位长为 64。

### 4. 安全边界（对应「【四】安全边界」）

| 结论              | 说明                                                   |
|:--------------- |:---------------------------------------------------- |
| 计时侧信道           | `mod_pow` 按指数二进制位分支，运算次数随密钥位变化，可统计推断私钥 d             |
| 随机源非密码学安全       | `random_prime` 默认接收 `JavaRandom`（48 位 LCG），输出序列可被预测  |
| 小位宽可分解          | 64 位模数用 Pollard ρ / ECM 在普通机器上数秒内可分解                 |
| 无填充             | `c = m^e mod n` 是确定性的，存在选择明文、低指数广播、小消息攻击             |
| Miller-Rabin 边界 | ≤ 64 位用确定性见证集；超过 `3317044064679887385961981` 退化为概率判定 |

生产做法：RSA ≥ 2048 位；加密用 RSA-OAEP、签名用 RSA-PSS；随机数用 CSPRNG（`os.urandom` / `secrets`）；实现委托给 `cryptography` / `PyCryptodome`，不要自行实现。

## 第二部分　小位宽 RSA（`rsa.py`）

### 5. 经典公开向量（对应 `rsa.py` 的「【一】已知公开向量自检」）

参数：`p = 61`，`q = 53`，`n = 3233`，`φ(n) = 3120`，`e = 17`，`d = 2753`。

| 校验                          | 期望输出   |
|:--------------------------- |:------ |
| `φ(n) = (p−1)(q−1)`         | `3120` |
| `d = e⁻¹ mod φ(n)`          | `2753` |
| 加密 `c = 65^17 mod 3233`     | `2790` |
| 解密 `m = 2790^2753 mod 3233` | `65`   |
| CRT 解密与直接解密一致               | `65`   |
| `e·d ≡ 1 (mod φ(n))`        | `1`    |

### 6. 固定种子确定性向量（对应「【二】固定种子可复现」与「【四】」）

#### 6.1 密钥（固定种子 → 确定性密钥）

随机源 `JavaRandom(seed)` 精确复刻 `java.util.Random`（48 位 LCG）；同一 seed 连续生成两次，`n` / `e` / `d` 完全相同。

| 用例  | 位宽  | 种子       | p                    | q                    | n                                       | φ(n)                                    | e     | d                                      |
|:--- | ---:| --------:|:-------------------- |:-------------------- |:--------------------------------------- |:--------------------------------------- | -----:|:-------------------------------------- |
| K1  | 64  | 2025     | 3955599587           | 2878846133           | 11387562574731347071                    | 11387562567896901352                    | 65537 | 376880589739664297                     |
| K2  | 64  | 7        | 3667184063           | 3999354053           | 14666367445456057339                    | 14666367437789519224                    | 65537 | 9288527806779251185                    |
| K3  | 128 | 20250909 | 15438973180112575271 | 16256863097279487271 | 250989273351659855709906529422273875441 | 250989273351659855678210693144881812900 | 65537 | 30243408939348122133921751739706298373 |

校验（全部通过）：`p·q == n`；`e·d mod φ(n) == 1`；`n.bit_length()` 达到目标位宽（64 / 128）。

#### 6.2 单块整数加解密（K1，seed = 2025）

`c = m^e mod n`，`m = c^d mod n`：

| 明文 m                        | 期望密文 c               | 解密回 m |
| ---------------------------:| --------------------:| -----:|
| 0                           | 0                    | 0     |
| 1                           | 1                    | 1     |
| 2                           | 4208667619380246267  | 2     |
| 42                          | 10689628196788140947 | 42    |
| 11387562574731347070（= n−1） | 11387562574731347070 | 同左    |

> `m = n−1 ≡ −1 (mod n)`，且 e 为奇数 ⇒ `(−1)^e ≡ n−1`。

#### 6.3 128 位密钥（K3，seed = 20250909）

| 输入                                                      | 期望                                                                         |

| `encrypt_string(pub, "Secure E-Commerce")`（16 字节 → 2 块） | `[0xb73fb66af58ac79ce67cdd5b11634c67, 0x31fa591a0d893b659bc05f0b25d3680d]` |

### 9. CRT 与直接解密性能（对应「【五】复杂度与性能实测」）

同一密钥取 `c = encrypt(pub, 123456789)`，各取多次运行最优值：

| 密钥位宽   | 直接解密      | CRT 解密    | 加速比   |
|:------ | ---------:| ---------:| -----:|
| 128 位  | 30.40 μs  | 24.00 μs  | 1.27× |
| 256 位  | 100.30 μs | 60.90 μs  | 1.65× |
| 512 位  | 532.30 μs | 208.40 μs | 2.55× |
| 1024 位 | 2.97 ms   | 1.07 ms   | 2.78× |

加密（128 位密钥，e = 65537）：`3.00 μs`——公开指数仅 17 位，故远快于解密。

> `decrypt_crt` 与 `decrypt` 结果一致（K1 / K3 / 3233 密钥均测）。

### 10. 安全边界实测（对应「【六】安全边界」）

| 实验           | 输入                              | 实测结果                         | 结论               |
|:------------ |:------------------------------- |:---------------------------- |:---------------- |
| Pollard ρ 分解 | K1 的 `n = 11387562574731347071` | 约 144 ms 内分解出因子 `2878846133` | 64 位模数可被离线瞬间攻破   |
| 确定性          | 同一 `m` 连续两次加密                   | 密文完全相同                       | 无填充 ⇒ 无随机性，可字典攻击 |
| 乘法同态         | `E(m1)·E(m2) mod n`             | `== E(m1·m2 mod n)`          | 攻击者可无密钥操纵明文      |
| 计时侧信道        | `mod_pow` 按指数位分支                | 分支数随密钥位变化                    | 可统计推断私钥比特        |
| 非安全随机源       | `JavaRandom`（48 位 LCG）          | 序列可预测                        | 生产须改用 CSPRNG     |

- **性能与复杂度**：见 `docs/crypto/week05/算法说明.md`（时间复杂度与空间复杂度、性能实测两节）；安全边界见该文的安全边界一节。
