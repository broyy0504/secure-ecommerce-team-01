# 测试向量表


## 1. 固定参数与约定

| 项目 | 说明 |
|---|---|
| 模幂语义 | `pow(base, exp, mod)`；`mod = 1` 时结果恒为 `0` |
| RSA 类型 | 教科书 RSA，无填充 |
| 密钥参数 | `p = 61`，`q = 53`，`n = 3233`，`φ(n) = 3120`，`e = 17`，`d = 2753` |
| 密钥校验 | `e × d = 46801`，`46801 mod 3120 = 1` |
| 字符串编码 | UTF-8 |
| RSA 字符串加密 | 按 UTF-8 字节逐字节加密，每字节 `m ∈ [0, 255]`，均满足 `m < n = 3233` |
| 整数边界 | 明文整数 `0`、`1` 直接作为 `m` 加密，解密后仍为整数 |

## 2. 模幂测试向量

| ID | 输入 | 期望输出 | 覆盖边界 |
|---|---|---|---|
| M01 | `pow(0, 5, 13)` | `0` | 输入 `0` |
| M02 | `pow(1, 5, 13)` | `1` | 输入 `1` |
| M03 | `pow(5, 0, 13)` | `1` | 指数为 `0` |
| M04 | `pow(5, 3, 1)` | `0` | 模数为 `1` |
| M05 | `pow(7, 0, 1)` | `0` | 指数为 `0` + 模数为 `1` |
| M06 | `pow(2, 10, 1024)` | `0` | 整除/溢出边界 |
| M07 | `pow(123456789, 0, 1000000007)` | `1` | 大底数 + 指数为 `0` |
| M08 | `pow(int('41' * 100, 16), 1, 2**4096 - 1)` | `int('41' * 100, 16)` | 超长输入 |

| R02 | RSA 加密 | 明文整数 `1`，公钥 `(n=3233, e=17)` | 密文 `1` | 输入 `1` |
